# Scoped web and reference tools

Klukai can use existing host MCP servers through `config/mcp-tools.json`.
`KLUKAI_MCP_CONFIG=/config/mcp-tools.json` enables this configuration; an empty
value preserves the legacy `MCP_URL` client. Invalid nonempty configuration
fails closed. Every configured server has an explicit tool allowlist enforced
during discovery and invocation, including the local-model fallback.

The reference gateway at host port 9126 supplies 21 public tools: web/news
metasearch, weather, units and currency, symbolic simplification, arXiv/DOI
references, Stack Exchange, Hacker News and public CVE/OSV data. Administrative
and private-fleet tools are not exposed. The installed offline encyclopedia has
no books, so it is omitted. Public queries should contain only the information
needed for the lookup; retrieved instructions cannot grant additional authority.
She is prompted to cite source URLs and report lookup failures.

Brave's existing MCP server at host port 9152 supports seven selected tools:
web, news, images, video, local/place search and LLM context. Its API key remains
inside that existing server. `KLUKAI_BRAVE_ENABLED=false` leaves these tools
undiscovered and uncallable. Enable it only after the owner confirms a hard
no-charge usage cap or separately authorizes paid Brave requests. The existing
Claude spending exception does not grant permission for Brave charges. Free
metasearch remains available while this is unresolved.

## Credentials and deployment

Set `KLUKAI_MCP_SECRETS_DIR` to
`/home/jalsarraf/.local/share/mcp-stack/klukai`. Its mode-0600 `gateway.token`
is a dedicated read-only scoped gateway key, mounted through its mode-0700
directory at `/run/klukai-mcp`. Never put the key in Git, documentation, model
messages or logs. The host gateway rotates keys weekly; install the isolated
[pickup service and timer](../../ops/amarillo/mcp/README.md) to copy only this
client's successor key every 15 minutes. The client rereads the file for every
request, so atomic replacement remains visible without restarting Klukai.

The core reaches existing servers using Docker's `host.docker.internal`
host-gateway mapping. No new MCP server, shared-server code change or GPU
service restart is required. Sonnet primary, Dominus fallback, voice and image
settings are independent of this configuration.

The client supports JSON and SSE, isolated sessions, bounded response sizes,
paginated catalogs and session recovery. Only a session-expired 404 is retried;
ordinary failures and timeouts are not replayed automatically. Discovery has
shorter timeouts than tool execution, and missing servers do not remove tools
from healthy servers. Schema caching expires after 60 seconds; empty results
are not cached.

## Verification and rollback

Fixture tests cover transport/session behavior, invocation policy, credential
rotation, route selection and cited tool responses. Live probes run from the
core Docker network demonstrated public web search, current weather, unit
conversion, arXiv retrieval and Hacker News, plus rejection of an administrative
tool. No Brave search was issued while its allowance was unresolved.

Predeployment checks on 2026-10-14: 4,852 core tests passed, 57 skipped and one
performance test deselected (10 existing warnings); changed modules passed
Ruff and mypy. The final isolated image discovered exactly 21 allowed tools
and the gateway itself rejected an administrative call with the scoped key.
The MCP stack self-test ended `43 passed, 0 failed`. The pickup service's first
run succeeded and its 15-minute timer is active. A separate in-memory gateway
check verified a successor key works with an existing MCP session.

Production was deployed directly from implementation commit `3cb5c64` using
core image `sha256:7c65014c2f55218b043cbdbb944c7429c06aea6861f34de63d7e3c0583b853f2`.
The core and `/health` are healthy, all existing runtime environment values
were preserved, and the live catalog contains 21 tools. The dedicated `claude`
test account completed a real WebSocket conversation through
`claude-sonnet-5-5`: she called `search_mcp__search` and returned the official
Python downloads URL with source links. A separate live conversion returned
`1 mile = 1.609344 kilometer`. Brave remains disabled; no Brave search was made.

The prior image is retained as `companion-core:before-web-tools-20261014`.
Private environment/Compose rollback files are under
`~/.local/share/klukai/deploy-backups/web-tools-20261014/`. These files contain
private configuration and must never be published.

To disable this integration, clear `KLUKAI_MCP_CONFIG` and recreate only
`companion-core`; this restores the legacy client. Disable the pickup timer if
retiring the dedicated key. Retain the previous core image and private `.env`
backup for deployment rollback. Neither rollback needs to alter stored chat,
images, voice artifacts or the GPU stack.
